Built for big files

Speed when there’s headroom.

Majra does the unglamorous work: splits files, keeps every connection busy, verifies what arrives, and lets you close the window.

MULTI-NET

Every connection, together

Wi-Fi, Ethernet, USB tethering and mobile data can all carry the same file at once. Majra keeps each stream on the network you chose.

STREAMS

2 to 64 connections

Pick 2, 4, 8, 16 or 32 parallel connections. Turbo mode can scale to 64 per network when the server allows it.

EXTRACT

Download + extract

ZIP, RAR and TAR archives — including .tar.gz, .tar.bz2 and .tar.xz — unpack as they download. No second pass.

DIRECT

Direct links stay direct

Paste a file URL and go. No in-between page, no forced account. Signed-in downloads work through the extension.

BROWSER

From browser to Majra

The Chromium extension hands downloads to the app with the browser’s cookies, then gets out of the way.

TRAY

Closes to the tray

Keep downloading after you close the window. Start Majra with Windows so it’s ready in the background.

Questions, answered

The honest version, rough edges included.

If you can’t find your answer, open an issue on GitHub.

Open an issue
Does Majra really combine my connections?
Yes — when more than one network is active and the server supports range requests. It splits the file into blocks and binds streams to different interfaces. A server that limits one connection, or an ISP that caps your line, still sets the ceiling.
Which versions of Windows are supported?
Windows 10 and 11, 64-bit. The current installer is built for x64.
Is it free?
Yes. Majra is free and open source under the MIT license. There is no account, subscription or ad.
Why does Windows warn me?
The installer is unsigned, so SmartScreen can’t verify its publisher. Choose More info → Run anyway, or build from source. Signing requires a paid certificate, which the project does not have yet.
Where is the browser extension?
It’s a separate zip download, not inside the installer and not on the Chrome Web Store. Install it manually with Developer mode; steps are above.
Which archives extract while downloading?
ZIP, RAR and TAR archives, including .tar.gz, .tar.bz2 and .tar.xz. .7z and multipart archives can’t be stream-extracted; download them fully, then extract with your usual tool.
Will it make every download faster?
No. Majra makes the most of the connections and server capacity you have. If the server limits you to one slow stream, more connections won’t help. Turbo mode can even hurt on weak hardware or strict servers.
Does it collect my data?
Majra keeps settings and download history on your PC. The browser extension only talks to Majra on 127.0.0.1 — not to developer servers. See the extension privacy policy for details.
Can I use it for torrents?
Yes, .torrent files and magnet links can be opened with Majra. The installer doesn’t take over your torrent associations.
