# دليل استعمال Tayyar

## التثبيت

1. شغّل `tayyar-1.0.0-setup.exe`.
2. Windows غادي يعطيك تحذير SmartScreen (لأن التطبيق ماشي موقّع بشهادة). اضغط **More info → Run anyway**.
3. اختر مجلد التثبيت، وخلّي «Create desktop shortcut» مفعّل.

## أول تحميل

1. افتح Tayyar.
2. اضغط **New download** (أو `Ctrl+N`)، والصق الرابط.
3. اختر المجلد وعدد الاتصالات (Auto كافية عادةً).
4. اضغط **Start**.

## Turbo — أقصى سرعة

`الإعدادات (Settings) → Power & automation → Turbo mode`

|                  | عادي   | Turbo   |
| ---------------- | ------ | ------- |
| اتصالات لكل شبكة | 8 → 32 | 16 → 64 |
| حجم البلوك       | 8 MB   | 4 MB    |

فعّله إلى إذا كان السيرفر يسمح بعدة اتصالات. إذا لاحظت أن السيرفر يرفض أو يبطّأ، رجّعو Off.

## دمج الشبكات (WiFi + Ethernet + USB + 4G)

- كل شبكة عندها اتصال إنترنت مستقل تظهر تلقائياً في قائمة الشبكات.
- فعّل الشبكات اللي تحب تدمجها، والباقي Off.
- التطبيق يقسّم الملف ويوزّع البلوكات على الشبكات حسب سرعة كل واحدة.

> ملاحظة: الدمج يخص التحميلات اللي تبدأ من داخل Tayyar فقط، ماشي كل ترافيك الجهاز.

## الإعدادات المفيدة

- **Sort finished files**: يرتّب الملفات في مجلدات Video / Audio / Programs / Documents / Archives / Images.
- **Scan with Windows Defender**: فحص تلقائي بعد كل تحميل.
- **Watch the clipboard**: كي تكوبي رابط ملف، يفتح مباشرة في New download.
- **Shut down when finished**: يطفي الجهاز بعد 60 ثانية من نهاية القائمة. للإلغاء: `shutdown /a`.
- **Schedule**: تحديد وقت ويوم التحميل.
- **Speed limits / Data budgets**: حد أقصى للسرعة أو حجم البيانات لكل شبكة.

## المتصفح

المشروع فيه extension (Chrome/Firefox) في مجلد `extension/`، لكنه ماشي مثبّت مع الـinstaller. تبنيو بـ:

```powershell
npm run build:extension
```

ثم `chrome://extensions` → Developer mode → Load unpacked → `extension/dist/chrome`.

## استئناف التحميل

التحميلات تُحفظ تلقائياً. إذا طفيت الجهاز أو سقط الاتصال، ارجع لـTayyar واضغط Resume — يكمل من نفس البلوك.

## وين الملفات؟

- التحميلات: المجلد اللي تخترو (افتراضياً `Downloads`).
- إعدادات التطبيق: `%APPDATA%\Tayyar\app-settings.json`.

## مشاكل شائعة

| المشكلة          | الحل                                                                   |
| ---------------- | ---------------------------------------------------------------------- |
| SmartScreen      | More info → Run anyway (التطبيق ماشي موقّع)                            |
| شبكة ما تظهرش    | تأكد أنها متصلة وتعطي إنترنت؛ أعد فتح التطبيق                          |
| السرعة ما زادتش  | السيرفر يحدّ الاتصالات؛ جرّب Turbo Off وشوف الفرق                      |
| التحميل ما يبداش | تأكد من الرابط، وجرّب «Download with browser» إذا كان محمي بتسجيل دخول |
